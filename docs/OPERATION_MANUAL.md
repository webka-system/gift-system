## 1. はじめに

このシステムは、**QRコードを印刷した物理カードを配り、受け取った人がスマホでQRを読むと専用ページが開く**仕組みです。用途の違う**2種類**があります。

| 種類 | 用途 | 受け取った人が見る画面 |
|---|---|---|
| **カタログギフト** | 価格帯ごとに選べる商品の中から1つを選んでもらい、住所を入力してもらって発送する | 商品を選ぶ → 住所を入力 → 完了 |
| **株主優待クーポン** | 株主に、ECサイト（お取り寄せ本舗）で使える**割引クーポンコード**を渡す | 専用のクーポンコードが表示される → コピーしてお店で使う |

どちらも、管理画面で「**種別を作る → QRを一括生成する → 印刷用の一覧を出して工場に渡す → 物理カードを発送 → 受け取った人がQRを読む**」という流れは共通です。

**この2種類は、管理画面の上部の切替ボタンで完全に分かれています**（[第5章](#5-モード切替)）。作業前に「今どちらを扱っているか」を必ず確認してください。

## 2. 管理画面へのログインと画面の見方

1. ブラウザで管理画面のURLを開きます。
2. メールアドレスとパスワードを入力して**ログイン**します。
3. 画面の上に、以下が並んでいます。
   - 一番上：**取り扱い**の切替（「カタログギフト」「株主優待クーポン」）。
   - その下：**タブ**（カード種別／選定可能商品／QR生成／QR一覧／印刷／NE連携 など）。タブは今のモードによって変わります。
4. 「カタログギフト」を選んでいるときは**青**、「株主優待クーポン」を選んでいるときは**紫**の色で、今どちらのモードかが分かるようになっています。

> 💡 各タブは、開くと自動でその内容を読み込みます。最新の状態が見えないと感じたら、ブラウザを再読み込み（更新）してください。

## 3. カタログギフトの運用手順

> 画面上部の取り扱いを **「カタログギフト」** にしてから操作してください（青色の状態）。

### 3-1. カード種別を作る（価格帯を登録）

「種別」とは、**価格帯ごとのまとまり**です（例：1万円ギフト、3万円ギフト）。選べる商品はこの種別にぶら下げて登録します。

1. **「カード種別」タブ**を開きます。
2. 下の「種別の登録 / 編集」フォームに入力します。
   - **表示名**（必須）：例「3万円ギフトカード」。
   - **価格帯（円）**（必須）：例「30000」。
   - **ギフトカード管理商品コード**（任意）：自社の管理コードがあれば。
   - **有効期限（日数・空欄で無期限）**（任意）：カードを生成した日から何日で期限切れにするか。例「90」。空欄なら無期限。
3. **「種別を登録」**を押します。上の一覧に追加されます。
4. 直したいときは一覧の行の**「編集」**、使うのをやめるときは**「無効化」**を押します。

### 3-2. 選定可能商品を登録する（受け取り者が選ぶ商品）

受け取り者が選べる商品を、種別ごとに登録します。

1. **「選定可能商品」タブ**を開きます。
2. 上の**「対象の種別」**で、商品を登録したい種別を選びます。
3. 「商品の登録」フォームに入力します。
   - **商品名**（必須）。
   - **NE商品コード**（必須）：発送管理（ネクストエンジン）に渡す実際の商品コード。**間違えると別の商品が発送されます**ので正確に。
   - **商品説明**（任意）。
   - **セット内容**（任意）：1行につき1項目で入力（例：唐揚げ200g／ハンバーグ5個…）。
   - **メイン画像**（任意）：一覧やサムネに出る画像。
   - **追加画像**（任意・最大4枚）：詳細で見せる画像。
4. **「商品を登録」**を押します。
5. 登録した商品は一覧に出ます。**「詳細」**で見え方を確認、**「編集」**で修正、**「無効化」**で受け取り者に出さないようにできます。

### 3-3. QRコードを一括生成する

物理カードに印刷するQR（の元になるURL）をまとめて作ります。

1. **「QR生成」タブ**を開きます。
2. **種別**を選びます。
3. **生成個数**を入力します（例：100）。
4. **「生成する」**を押すと、その枚数分のQRカードが作られます。
5. 1回の生成が1つの「**ロット**」になります（いつ・何枚作ったかのまとまり）。あとで印刷や絞り込みのときに、このロット単位で扱えます。

> 💡 QRカードは作った時点では「まだ誰のものでもない空のカード」です。受け取り者が使って初めて注文になります。

### 3-4. 印刷用URL一覧（Excel）を出して工場に渡す

物理カードを印刷する工場に渡す、URLの一覧表（Excel）を出します。

1. **「印刷」タブ**を開きます。
2. 出力する範囲を指定します（組み合わせOK）。
   - **種別**：特定の種別だけ。
   - **ロット（生成）**：特定の生成回だけ。
   - **生成日（範囲）**：期間で。
   - **未印刷分のみ**：まだ出していない分だけ。
   - **出力分を「印刷済み」にする**：チェックすると、出した分に印刷済みの印を付けます（二重に入稿しないため）。
   - **A列（URL）のみで出力**：工場がURL1列だけを求める場合。
3. **「Excelをダウンロード」**を押すと、Excelファイルが保存されます。
4. このExcelを印刷工場に渡します。工場がURLをQRコードに変換して、物理カードに印刷します。

### 3-5. 受注（受け取り者の確定）を確認する

受け取り者が商品と住所を確定すると、一覧で状態が変わります。

1. **「QR一覧」タブ**を開きます。
2. 上のフィルタで絞り込めます（種別／状態／NE投入／ロット／生成日／有効期限／検索）。**検索**は、名前・カナ・メール・memo・トークンの一部で探せます。
3. 一覧の各列の意味：
   - **生成日 / 有効期限**：いつ作ったか、いつまで有効か。
   - **状態**：下の「状態バッジの意味」を参照。
   - **種別 / 受け取り者名 / 使用日時**。
   - **memo**：担当者の自由メモ（受注番号の突合などに）。入力して「memo保存」で保存。
   - **操作**：**詳細**（中身を見る）／**URLコピー**（受け取り者URLをコピー）／**memo保存**。
4. **「詳細」**を押すと、選ばれた商品・配送先住所・連絡先・配達希望・確定日時・発送管理（NE）への投入状態などが見られます。

#### 状態バッジの意味（カタログ）

| バッジ | 意味 |
|---|---|
| **未使用**（青） | まだ受け取り者が使っていない |
| **期限切れ**（赤） | 有効期限を過ぎて未使用のまま（受け取り不可） |
| **使用済**（灰） | 受け取り者が商品・住所を確定した |
| **NE投入済 / CSV出力済**（緑） | 発送管理（ネクストエンジン）へ受注が渡った |
| **NE受付済(確認待ち) / NE投入中**（黄） | 投入の処理中。少し待つと確定します |
| **NE投入失敗**（赤・太字） | ⚠ **発送管理に受注が渡っていない状態。放置すると発送漏れになります。** 下記の対処が必要 |
| **NE未投入**（橙） | まだ発送管理へ渡していない |

### 3-6. 発送管理（NE）への投入が失敗したときの対処

**「NE投入失敗」（赤）**は、注文は確定したのに発送管理へ受注が渡っていない状態です。**そのままだと商品が発送されません**。見つけたら対処してください。

1. QR一覧で**「NE投入」フィルタを「NE投入失敗」**にすると、失敗分だけ表示できます。
2. 対象カードの**「詳細」**を開きます。
3. **「ネクストエンジン投入」**の欄に、失敗の理由と、状態に応じたボタンが出ます。
   - **NEへ手動投入**：もう一度投入します（確認ダイアログ→「受付済」になります）。
   - **取り込み結果を確認**：受付済みのものの結果を確認します（成功で「投入済」、失敗なら理由を表示）。
4. 押した直後は「受付済」になり、**少し待ってからもう一度「取り込み結果を確認」**を押すと、投入完了／失敗が確定します。
5. 「NE連携」タブの**「未投入を投入・受付済を確認」**ボタンで、未投入・受付済をまとめて処理することもできます。

> なぜ大事か：この失敗を放置すると、注文された商品が発送されません。**定期的に「NE投入失敗」を確認する**運用にしてください（[第7章](#7-日常運用のチェックポイント)）。

### 3-7. 受注内容の編集・やり直し・有効期限の延長

カード「詳細」の下の方に、管理者操作があります。

- **受注内容を編集**：確定済みの選択商品・住所・メール・配達希望を直します。
- **未使用に戻す（やり直し）**：受け取り者にもう一度入力してもらいたいとき。カードを未使用に戻します（直前の内容は履歴に残ります）。
- **有効期限の管理（延長・上書き）**：期限切れのカードを救済したいときなどに、日数を上書きして期限を延ばせます（空欄で保存すると元に戻ります）。

> ⚠ すでに発送管理へ投入済みのカードを編集・やり直しした場合、**発送管理側は自動では変わりません**。必要なら発送管理側も手で直してください（画面に注意が出ます）。

## 4. 株主優待クーポンの運用手順

> 画面上部の取り扱いを **「株主優待クーポン」** にしてから操作してください（紫色の状態）。
> クーポンは、株主がQRを読むと**その人専用の割引コードが表示される**仕組みです。商品選択や住所入力はありません。

### 4-1. クーポン種別を作る（割引内容を登録）

1. **「クーポン種別」タブ**を開きます。
2. 「クーポン種別の登録 / 編集」フォームに入力します。
   - **表示名**（必須）：例「株主優待10%OFF」。
   - **割引方式**（必須）：**割引率（%）** か **割引額（円）** を選びます。
   - **割引率（%）／割引額（円）**（必須）：例「10」（10%OFF）や「3000」（3000円OFF）。
   - **最低購入額（円・空欄で下限なし）**（任意）：この金額以上の買い物で使える、という下限。
   - 画面に出ている**固定設定**：会員限定＝ON／お一人様1回／対象＝全商品（これは変更できません。株主優待の共通ルールです）。
3. **「クーポン種別を登録」**を押します。

> 💡 有効期限はここでは決めません。**QRを生成するときに絶対日付で指定**します（株主優待は回ごとに期限が変わるため）。

### 4-2. クーポンQRを生成する（有効期限を指定）

1. **「QR生成」タブ**を開きます（クーポンモードなので、クーポン種別が選べます）。
2. **種別**（クーポン種別）を選びます。
3. **生成個数**を入力します。
4. **クーポン有効期限**（日付）を指定します。**この日付が、QRの受け取り期限であり、発行されるクーポンの有効期限**になります。
5. **「生成する」**を押します。

### 4-3. 印刷用Excelを出す

カタログと同じ「印刷」タブから出します（[3-4](#3-4-印刷用url一覧excelを出して工場に渡す)と同じ操作）。クーポンモードで開くと、**クーポンのカードだけ**が対象になります。出したExcelを工場に渡します。

### 4-4. 株主がQRを読むと何が起きるか

- 株主が物理カードのQRを読むと、**その人専用のクーポンページ**が開きます。
- 初めて開いたとき、システムが**その場でクーポンを1つ発行**し、**コードを画面に大きく表示**します（「発行しています…」の表示のあとコードが出ます）。
- 2回目以降に同じQRを開くと、**同じコードがそのまま表示**されます（新しく作り直したりはしません）。株主がコードを忘れても、もう一度開けば確認できます。
- ページには、**コードのコピーボタン**、**割引内容**、**有効期限**、そして**①会員登録 → ②商品を選ぶ → ③カゴでコードを入力**という使い方の案内と、お店（お取り寄せ本舗）へのリンクが表示されます。

### 4-5. クーポンの状態を確認する

1. **「QR一覧」タブ**（クーポンモード）を開きます。クーポンのカードだけが表示されます。
2. 状態バッジの意味：

| バッジ | 意味 |
|---|---|
| **クーポン**（紫） | クーポンのカードである印 |
| **未発行** | まだ株主がアクセスしておらず、コードが発行されていない |
| **クーポン発行済**（緑） | 株主がアクセスし、コードが発行された |
| **発行失敗**（赤・目立つ） | ⚠ 発行しようとして失敗した状態。株主がコードを受け取れていません。対処が必要（[4-6](#4-6-発行に失敗したときの手動再発行)） |

3. カードの**「詳細」**を開くと、**発行されたクーポンコード・発行日時・状態・失敗した場合の理由**が確認できます。

### 4-6. 発行に失敗したときの手動再発行

**「発行失敗」（赤）**は、株主がアクセスしたのにクーポンが発行できなかった状態です。株主はコードを受け取れていません。

1. QR一覧（クーポンモード）で対象カードの**「詳細」**を開きます。
2. 「クーポン発行」欄に失敗理由が表示され、**「クーポンを再発行」**ボタンが出ます。
3. 押すと確認ダイアログのあと、もう一度発行を試みます。成功するとコードが表示されます。
4. なお、**管理画面から手動で発行したクーポンは、名前のうしろに `【再発行 M/D】` が付きます**（例：「株主優待10%OFF【再発行 7/24】」）。これは、あとでお店（MakeShop）側の管理画面でクーポンを見たときに「これは手動で発行し直したもの」と分かるようにするためです。

> 💡 **すでに発行済みのカードでも、再発行できます**（詳細の「クーポンを再発行」）。その場合、確認ダイアログで「別のクーポンが作られます」と警告が出ます。表示されるコードは新しいものに置き換わります。特別な理由がなければ、発行済みのものを再発行する必要はありません。

### 4-7. お店（MakeShop）側でクーポンを確認したいとき

発行されたクーポンは、お店の管理画面（MakeShop）にも登録されています。管理者がそちらで確認する場合：

- クーポン名は「（クーポン種別の名前）」＝手動発行なら末尾に `【再発行 M/D】`。
- 割引・会員限定・お一人様1回・有効期限が、種別で設定した通りになっているかを確認できます。
- クーポンコードは、管理画面のカード詳細に表示されているものと同じです。

## 5. モード切替

画面上部の**「取り扱い」**で、**カタログギフト**と**株主優待クーポン**を切り替えます。

- **今どちらを扱っているか**は色で分かります：**カタログ＝青**、**クーポン＝紫**。
- 種別の作成・QR生成・一覧・印刷は、**選んでいるモードの側だけ**が対象になります。
- **間違い防止**：カタログモードでは、クーポン種別は選べません（逆も同じ）。誤って別の種類でQRを作ってしまう事故を防いでいます。
- クーポンモードには「選定可能商品」「NE連携」タブは出ません（クーポンには不要なため）。

> ⚠ 作業を始める前に、**必ず今のモードを確認**してください（色でチェック）。特にQR生成は、意図した種類で作っているか確認を。

## 6. よくあるトラブルと対処

### Q. 受け取り者／株主が「ページが開かない・使えない」と言ってきた

まず、そのカードを管理画面で探して（QR一覧の検索でトークンや名前で検索）「詳細」で状態を確認します。

- **「期限切れ」**になっている → 有効期限を過ぎています。カタログなら「有効期限の管理」で延長できます（[3-7](#3-7-受注内容の編集やり直し有効期限の延長)）。クーポンは期限延長ではなく、必要なら新しい期限でQRを作り直す運用です。
- **「使用済」**（カタログ）／**「クーポン発行済」**（クーポン）になっている → すでに使われています。二重に使えないようになっているため、正しい動作です。本人の勘違いか、別のカードの可能性を確認してください。
- カードが見つからない → QRの読み取り違い、または対象外のURLの可能性。お手元のカードのQRを読み直してもらってください。

### Q. 商品が発送されない（カタログ）

- QR一覧で状態が**「NE投入失敗」（赤）**になっていないか確認してください。なっていれば[3-6](#3-6-発送管理neへの投入が失敗したときの対処)の手順で再投入します。
- **放置すると発送漏れになります。** 失敗は必ず対処してください。

### Q. 株主がクーポンコードを受け取れていない

- QR一覧（クーポンモード）で状態が**「発行失敗」（赤）**になっていないか確認し、[4-6](#4-6-発行に失敗したときの手動再発行)で再発行します。

### Q. 二重に使われないか心配

- カタログは一度「使用済」になると、同じQRからは再入力できません。クーポンは一度発行するとコードは固定で、2回目以降は同じコードが出るだけです（新しく作られません）。**二重利用は仕組みで防止**されています。

## 7. 日常運用のチェックポイント

安定運用のため、定期的に（例：1日1回）以下を確認してください。

1. **カタログ：発送管理の投入失敗がないか**
   - QR一覧（カタログモード）→ NE投入フィルタを**「NE投入失敗」**にして、赤いカードが無いか確認。あれば[3-6](#3-6-発送管理neへの投入が失敗したときの対処)で対処。
   - **これが一番大事です**（放置＝発送漏れ）。
2. **クーポン：発行失敗がないか**
   - QR一覧（クーポンモード）で**「発行失敗」（赤）**のカードが無いか確認。あれば[4-6](#4-6-発行に失敗したときの手動再発行)で再発行。
3. **印刷入稿の抜け漏れ**
   - 新しく生成したロットを、印刷工場へ入稿し忘れていないか（印刷タブの「未印刷分のみ」で確認）。
4. **期限が近いカードの扱い**
   - 必要に応じて、QR一覧の有効期限フィルタ「期限が近い（7日以内）」で確認。
